# 00. Tổng quan dự án

> **Phiên bản:** `v1.0` · **Cập nhật:** 2026-11-13

## 1. Mục tiêu
Dự án mẫu minh họa cách vận hành **Kho Tài Liệu Sống** trên GitHub + GitBook + AI Agent.

## 2. Các vai trò (Roles)
- **Người đặt sân (User):** Tìm sân trống, đặt lịch và thanh toán cọc.
- **Chủ sân (Owner):** Quản lý lịch trống, xác nhận đơn và đối soát doanh thu.
- **BA / PO:** Chốt nghiệp vụ, cập nhật tài liệu và duyệt Version History.
